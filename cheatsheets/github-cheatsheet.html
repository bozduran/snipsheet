GitHub glossary

the platform words people throw around, in plain language
gh
GitHub's official command-line tool. Lets you do GitHub things — PRs, issues, releases — without leaving the terminal.
repository (repo)
A project hosted on GitHub: its files, history, issues, and pull requests.
fork
Your own server-side copy of someone else's repo, so you can change it freely and propose those changes back.
origin vs upstream
On a fork, “origin” is your copy and “upstream” is the original project you forked from.
pull request (PR)
A proposal to merge your branch's changes into another branch, where others can review and discuss them first.
draft PR
A pull request marked “not ready yet,” so reviewers know not to merge or review it formally.
merge / squash / rebase
The three ways to land a PR: a merge commit keeps every commit, squash collapses them into one, rebase replays them with no merge commit.
review
Feedback on a PR — you can approve it, request changes, or just comment.
issue
A tracked note for a bug, task, or idea, with discussion and labels.
GitHub Actions
GitHub's built-in automation that runs jobs (tests, builds, deploys) when things happen in your repo.
workflow
A YAML file in .github/workflows that defines an automated process for Actions to run.
run
One execution of a workflow — what you inspect when checking if CI passed or failed.
runner
The machine (GitHub-hosted or your own) that actually executes a workflow's jobs.
release
A packaged, named version of your project (tied to a tag), often with notes and downloadable files.
asset
A file attached to a release for people to download, like a built binary or zip.
gist
A small shareable snippet or set of files, hosted on GitHub like a tiny repo.
branch protection
Rules on a branch (e.g. main) that require reviews or passing checks before anything can merge.
CODEOWNERS
A file listing who automatically gets asked to review changes to certain paths.
PAT (token)
A personal access token — a password-like string used to authenticate to GitHub from scripts or HTTPS.
