PowerShell glossary

the words people throw around, in plain language
cmdlet
A built-in PowerShell command named Verb-Noun, like Get-Process. It returns objects, not plain text.
object
A thing with properties (data) and methods (actions). PowerShell passes objects down the pipeline, so you filter on properties instead of parsing text.
pipeline (|)
Sends the output of one command into the next, one object at a time.
parameter
An option for a command, written with a dash, like -Path. You only need to type enough letters to be unambiguous.
alias
A short nickname for a command, e.g. ls and gci both mean Get-ChildItem.
$_ / $PSItem
The current object inside Where-Object or ForEach-Object.
script block
Code in curly braces { } that can be passed around and run later, e.g. to a filter or to a remote machine.
hashtable
Key-value pairs: @{ Name = "x"; Id = 1 }. Used for headers, filters, splatting and building objects.
PSCustomObject
A quick way to build your own object: [pscustomobject]@{ Name = "x" }.
splatting
Passing parameters from a hashtable with @params instead of one long line.
provider / PSDrive
Lets non-file things look like folders: the registry (HKCU:), environment variables (Env:), certificates (Cert:).
module
A package of commands you install and import, e.g. from the PowerShell Gallery.
profile ($PROFILE)
A script that runs at the start of every session. The place for aliases and settings.
execution policy
A safety setting that controls whether scripts may run. A guard rail, not a real security boundary.
call operator (&)
Runs a command stored in a string or variable: & "C:\Program Files\x.exe".
dot-sourcing
. .\file.ps1 runs a script in your current scope, so its functions and variables stay available.
streams
Separate output channels: 1 success, 2 error, 3 warning, 4 verbose, 5 debug, 6 information. *> redirects all of them.
terminating error
An error that stops execution and can be caught by try/catch. Non-terminating errors only print and carry on, unless you use -ErrorAction Stop.
remoting
Running commands on other machines over WinRM (or SSH in PowerShell 7).
PowerShell 5.1 vs 7
5.1 (powershell.exe) ships with Windows. 7+ (pwsh) is cross-platform and newer. Items marked (7) here need PowerShell 7.
$LASTEXITCODE
The exit code of the last external program (git, robocopy...). $? says whether the last PowerShell command succeeded.
