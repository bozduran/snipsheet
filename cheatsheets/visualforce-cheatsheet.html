Visualforce glossary

the markup-side words people throw around, in plain language
Visualforce
Salesforce's tag-based UI framework — markup pages backed by Apex controllers.
component
An <apex:…> tag that renders a piece of UI, like a button or a table.
expression {!…}
Merge-field syntax that pulls data, reads properties, or wires actions to the controller.
controller
The Apex class that supplies a page its data and action methods.
standard controller
A built-in controller for one object — gives you save/edit/delete and the record for free.
standard list controller
A built-in controller for a set of records, with pagination, via recordSetVar.
custom controller
Your own Apex class fully driving the page.
controller extension
An Apex class that adds methods on top of a standard controller.
getter / setter
Methods (or properties) the page reads and writes through {!…}.
action method
A controller method run by a button/link; returns a PageReference (navigate) or null (stay).
PageReference
An object representing a URL or page to send the user to.
view state
The page's serialized state posted back on every request. Keep it small — there's a 170 KB limit.
reRender
An AJAX partial refresh of named components, without reloading the whole page.
$-globals
System merge variables like $User, $Label, $Resource, $Action.
static resource
An uploaded JS/CSS/image/zip file, referenced with $Resource.
JavaScript Remoting
Calling @RemoteAction Apex methods straight from JavaScript — fast and view-state-free.
action binding
Wiring a UI event (a click, a change) to a controller method.
recordSetVar
The variable that holds a list controller's records for iteration.
composition / template
apex:composition / insert / define — reusable page layouts.
Lightning stylesheets
SLDS styling for Visualforce via lightningStylesheets="true".
