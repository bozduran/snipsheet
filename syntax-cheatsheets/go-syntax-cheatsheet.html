Program structure

package main

import (
    "fmt"
    "os"
)

func main() {
    fmt.Println("hello", os.Args[1])
}
go mod init example.com/hello
go run .                  # compile + run
go build -o hello .       # produce a binary
go test ./...             # run all tests
  • Every file starts with a package. Executables use package main and func main.
  • Imports are per file, and unused imports or local variables are compile errors.
  • go fmt ./... is the formatter; the compiler enforces the syntax, the formatter enforces style.
  • Source files end in .go and live in a module (a directory with go.mod).

Variables & constants

var name string = "Ada"
age := 36                      // short declaration, inside a function
const Pi = 3.14159

const (
    KB = 1 << (10 * (iota + 1))
    MB
    GB
)

var (
    x, y = 1, 2
    ok   bool
)
  • := declares and assigns at least one new variable; it is not allowed at package level.
  • const values are compile-time constants. iota starts at 0 and increments per line in the block.
  • An inner := can shadow an outer variable. The compiler will not warn; keep scopes small.
  • Unused local variables and imports are errors, not warnings.

Strings & runes

s := "héllo"
len(s)                        // 6 bytes, not 5 characters
utf8.RuneCountInString(s)     // 5
s[0]                          // byte, not a rune
for i, r := range s {         // i is a byte index, r a rune
    _, _ = i, r
}
rs := []rune(s)
string(rs[1:])                // "éllo"

strings.Contains(s, "ell")    // true
strings.Split("a,b,c", ",")   // ["a" "b" "c"]
strings.Join([]string{"a", "b"}, "-") // "a-b"
strings.TrimSpace("  x  ")    // "x"
fmt.Sprintf("%s has %d bytes", s, len(s))

var b strings.Builder
b.WriteString("a")
b.WriteString("b")
b.String()                    // "ab"
  • Strings are immutable UTF-8 byte sequences. + copies; use strings.Builder in loops.
  • len counts bytes; range yields rune boundaries. Use []rune for character indexing.
  • == compares string bytes. Use strings.EqualFold for case-insensitive comparison.

Control flow

if n := len(xs); n > 0 {
    fmt.Println(n)
}

switch x {
case 1:
    fmt.Println("one")
case 2, 3:
    fmt.Println("two or three")
default:
    fmt.Println("other")
}

switch v := any(x).(type) {
case int:
    fmt.Println(v + 1)
case string:
    fmt.Println(v)
}

for i := 0; i < 3; i++ { }
for i, v := range xs { _, _ = i, v }
for _, v := range xs { _ = v }
for cond { }
for { break }

outer:
for i := 0; i < 2; i++ {
    for j := 0; j < 2; j++ {
        if j == 1 { continue outer }
        if i == 1 { break outer }
    }
}
  • for is the only loop; there is no while.
  • Switch cases do not fall through. Use fallthrough only when you mean it.
  • if and switch can declare a variable in the header; its scope ends with the block.
  • Labels let break and continue target an outer loop.

Arrays, slices & maps

var a [3]int                 // fixed-size array, zero-filled
a[0] = 1
s := []int{1, 2, 3}          // slice
s = append(s, 4)
window := s[1:3]             // view; shares the backing array
dst := make([]int, len(s))
copy(dst, s)

m := map[string]int{"a": 1}
m["b"] = 2
v, ok := m["a"]              // comma-ok
delete(m, "b")
for k, v := range m { _, _ = k, v }

var nilSlice []int
nilSlice = append(nilSlice, 1) // append works on nil
TypeUse it forWatch out
arrayfixed-size, value semanticslength is part of the type; copies the whole array
slicethe default sequenceshares backing storage; append may reallocate
mapkey → value lookupnil map write panics; iteration is unordered
map[T]struct{}a setmembership only; no value needed
  • A slice is a descriptor: pointer, length and capacity. len and cap can differ.
  • Maps are unordered and not safe for concurrent writes; use a mutex or a concurrent map design.
  • Reading a missing map key returns the zero value; use the comma-ok form when presence matters.

Functions & methods

func add(a, b int) int { return a + b }

func divmod(a, b int) (int, int) { return a / b, a % b }

func sum(xs ...int) int {
    total := 0
    for _, x := range xs { total += x }
    return total
}

func apply(f func(int) int, x int) int { return f(x) }

type Counter struct{ n int }
func (c Counter) Value() int { return c.n }
func (c *Counter) Inc() { c.n++ }
  • Functions can return several values: q, r := divmod(7, 2).
  • Parameters are passed by value. A pointer receiver can mutate the original; a value receiver cannot.
  • Variadic parameters are last: sum(1, 2, 3) or sum(xs...).
  • No overloading, default arguments or named optional parameters.

Structs & embedding

type User struct {
    ID    int    `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email,omitempty"`
}

u := User{ID: 1, Name: "Ada"}
u.Name = "Ada Lovelace"
p := &u
p.Email = "ada@example.com"

type Admin struct {
    User
    Level int
}
a := Admin{User: u, Level: 9}
a.Name                       // promoted field
a.User.Name                  // same field, explicit
  • Structs are values; assigning or passing one copies its fields (pointers inside are shared).
  • Tags are metadata used by reflection and packages such as encoding/json; they are not validation.
  • Embedding promotes fields and methods, but it is composition, not inheritance.
  • Exported fields start with an uppercase letter; unexported fields are package-private.

Interfaces & assertions

type Reader interface {
    Read(p []byte) (int, error)
}

type Closer interface {
    Close() error
}

type ReadCloser interface {
    Reader
    Closer
}

var r io.Reader = os.Stdin
if rc, ok := r.(io.ReadCloser); ok {
    defer rc.Close()
}

switch v := any(r).(type) {
case *os.File:
    fmt.Println("file", v.Name())
case io.Reader:
    fmt.Println("reader")
default:
    fmt.Println("other")
}
  • Interfaces are satisfied implicitly; there is no implements keyword.
  • An interface value holds a dynamic type and value. The zero interface is nil.
  • A typed nil pointer stored in an interface makes the interface non-nil; check the dynamic value too.
  • Accept interfaces, return concrete types; keep interfaces small and define them near the consumer.

Generics

func Map[T, U any](xs []T, f func(T) U) []U {
    out := make([]U, 0, len(xs))
    for _, x := range xs {
        out = append(out, f(x))
    }
    return out
}

type Number interface { ~int | ~int64 | ~float64 }

func Sum[T Number](xs []T) T {
    var total T
    for _, x := range xs { total += x }
    return total
}

type Stack[T any] struct { items []T }
func (s *Stack[T]) Push(v T) { s.items = append(s.items, v) }
  • Type parameters are declared in square brackets; constraints are interfaces.
  • ~T matches a type whose underlying type is T; any and comparable are common constraints.
  • Type inference works for many calls: Map([]int{1}, func(i int) string { return "x" }).
  • Methods cannot declare their own type parameters, and there is no specialization in Go.

Errors & panic

f, err := os.Open("data.txt")
if err != nil {
    return err
}
defer f.Close()

if err := doWork(); err != nil {
    return fmt.Errorf("doWork: %w", err)
}

if errors.Is(err, os.ErrNotExist) {
    // missing file: handle it
}

var pe *os.PathError
if errors.As(err, &pe) {
    fmt.Println(pe.Path)
}

var ErrNotFound = errors.New("not found")
return fmt.Errorf("load: %w", ErrNotFound)
  • Errors are ordinary values. Check them immediately and return them with context.
  • Wrap with %w; unwrap with errors.Is (sentinel) or errors.As (type).
  • panic is for programmer bugs, not expected I/O failures. recover belongs at a boundary, not everywhere.
  • Sentinel errors are package-level values; compare with errors.Is, not string matching.

Goroutines & channels

ctx, cancel := context.WithCancel(context.Background())
defer cancel()

jobs := make(chan int, 10)
var wg sync.WaitGroup
wg.Add(1)
go func() {
    defer wg.Done()
    for job := range jobs {
        process(job)
    }
}()
jobs <- 1
close(jobs)
wg.Wait()

ch := make(chan int)
go func() { ch <- 1 }()
v := <-ch

select {
case v := <-ch:
    _ = v
case <-ctx.Done():
    return
}
  • Goroutines are cheap but not free; every one needs a clear lifetime and exit path.
  • The sender closes a channel. A receive from a closed channel returns the zero value immediately.
  • Unbuffered sends and receives meet; buffered channels decouple them up to capacity.
  • Protect shared maps and counters with a mutex or use channels; run go test -race ./....

Testing

func TestAdd(t *testing.T) {
    if got := Add(2, 3); got != 5 {
        t.Fatalf("Add(2,3) = %d, want 5", got)
    }
}

func TestTable(t *testing.T) {
    tests := []struct {
        name string
        in   int
        want int
    }{{"one", 1, 2}, {"two", 2, 4}}
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            if got := Double(tt.in); got != tt.want {
                t.Errorf("Double(%d) = %d, want %d", tt.in, got, tt.want)
            }
        })
    }
}

func FuzzReverse(f *testing.F) {
    f.Add("abc")
    f.Fuzz(func(t *testing.T, s string) {
        if Reverse(Reverse(s)) != s {
            t.Errorf("round trip failed for %q", s)
        }
    })
}
go test ./...
go test -race ./...
go test -run TestAdd
go test -bench .
go test -cover
go test -fuzz FuzzReverse
  • Test files end in _test.go; test functions start with Test and take *testing.T.
  • Use table tests plus t.Run for readable failure names.
  • t.Parallel opts a test into parallel execution; shared state must be safe.
  • Fuzzing explores inputs you would not write by hand; seed it with valid and edge-case values.

Modern Go

nums := []int{3, 1, 2}
slices.Sort(nums)               // [1 2 3]
ok := slices.Contains(nums, 2)  // true

for i := range 3 {              // 0 1 2
    fmt.Println(i)
}

m := min(3, 1, 2)               // 1
largest := max(3, 1, 2)         // 3
clear(nums)

slog.Info("started", "port", 8080)

func Seq(yield func(int) bool) {
    for i := 0; i < 3; i++ {
        if !yield(i) { return }
    }
}
for v := range Seq {
    fmt.Println(v)
}
  • slices and maps cover sorting, searching, cloning and comparison without hand-written loops (1.21+).
  • min, max and clear are builtins (1.21+); for i := range n is 1.22+.
  • Range-over-func iterators are 1.23+. A module's go directive controls which language version the compiler accepts.
  • log/slog provides structured logging with levels and key/value pairs (1.21+).

Common gotchas

  • Writing to a nil map panics; reading from it is fine and returns the zero value.
  • Before Go 1.22, loop variables were reused; pass them into goroutines explicitly. Go 1.22 changed the semantics.
  • append may reuse the backing array, so two slices can observe each other's writes.
  • An interface holding a typed nil is not equal to nil.
  • Unchecked errors and leaked goroutines are the two most common production bugs.
  • defer arguments are evaluated immediately; defers in a loop accumulate until the function returns.
  • Use == on structs only when all fields are comparable. Slices and maps need slices.Equal or maps.Equal.
  • Integer division truncates, and mixing signed and unsigned types is a compile error.
