Program structure

package com.example.app;           // optional, mirrors the folder path

import java.util.List;             // one type
import java.util.*;                // whole package
import static java.lang.Math.*;    // static members

public class Main {                // file must be Main.java
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}

Compile and run

javac Main.java     # produces Main.class
java Main           # runs it
java Main.java      # compile + run in one step (11+)
  • One public top-level class per file, and the file name must match it.
  • Java is case-sensitive. Statements end with ;, blocks use { }.
  • Execution starts at main. java.lang is imported automatically.

Variables & casting

int x = 5, y = 10;              // several of one type
final double PI = 3.14159;      // constant, assigned once
var names = new ArrayList<String>();   // local inference (10+)

double d = 9.7;
int i = (int) d;                // narrowing cast: 9, truncates
long l = i;                     // widening is automatic
int r = 7 / 2;                  // 3  (integer division)
double q = 7 / 2.0;             // 3.5
int m = -7 % 3;                 // -1 (sign follows left side)
  • var works only for local variables with an initializer.
  • Locals must be assigned before use. Fields get the defaults above.
  • Scope ends at the closing } of the block that declared it.

Control flow

if (x > 0) { }
else if (x == 0) { }
else { }

switch (day) {                  // classic: needs break
    case 1: System.out.println("Mon"); break;
    default: System.out.println("?");
}

Switch expression 14+

String kind = switch (day) {    // no fallthrough
    case 6, 7 -> "Weekend";
    case 1 -> { String t = "Mon"; yield t; }
    default -> "Weekday";
};

Loops

for (int i = 0; i < 5; i++) { }
for (String s : list) { }       // for-each
while (cond) { }
do { } while (cond);

outer:                          // label
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (hit) break outer;   // leave both loops
        if (skip) continue;     // next iteration
    }
}

Arrays

int[] a = new int[5];           // zero-filled
int[] b = {1, 2, 3};

a.length                        // a field, no ()

Arrays.toString(b)              // "[1, 2, 3]"
Arrays.sort(b);   Arrays.fill(a, 7);

Indexes start at 0. An index out of range throws ArrayIndexOutOfBoundsException. Array size is fixed once created.

Methods

static int add(int a, int b) { return a + b; }
static void log(String msg) { System.out.println(msg); }

static int sum(int... nums) {           // varargs: last parameter
    int t = 0;
    for (int n : nums) t += n;
    return t;
}
static int add(int a, int b, int c) {   // overload: same name,
    return a + b + c;                   // different parameters
}
  • A return type is required. Use void when nothing comes back.
  • Java is pass-by-value. For objects the reference is copied, so a method can change the object but cannot repoint the caller's variable.

Classes & objects

public class Person {
    private String name;                 // field
    private static int count = 0;        // shared by all instances

    public Person(String name) {         // constructor: no return type
        this.name = name;
        count++;
    }
    public Person() { this("Unknown"); } // call another constructor

    public String getName() { return name; }

    @Override
    public String toString() { return "Person(" + name + ")"; }
}

Person p = new Person("Ada");

Inheritance & interfaces

abstract class Shape {
    abstract double area();             // no body
    void describe() { System.out.println(area()); }
}
class Circle extends Shape {            // one superclass only
    private final double r;
    Circle(double r) { super(); this.r = r; }
    @Override double area() { return Math.PI * r * r; }
}

interface Drawable {
    void draw();                        // public abstract by default
    default void hide() { }             // has a body (8+)
    static Drawable none() { return () -> { }; }
}
class Sprite implements Drawable, Cloneable {
    public void draw() { }
}

Type checks

Shape s = new Circle(2);         // upcast: implicit
Circle c = (Circle) s;           // downcast: explicit, may throw
if (s instanceof Circle k) {     // pattern matching (16+)
    k.area();
}

A class extends one class but can implement many interfaces. Override equals and hashCode together.

Records, enums, sealed

Record 16+

record Point(int x, int y) {        // immutable data carrier
    Point {                         // compact constructor
        if (x < 0) throw new IllegalArgumentException();
    }
    double dist() { return Math.hypot(x, y); }
}
Point p = new Point(1, 2);
p.x();                              // accessor is x(), not getX()

Sealed types 17+ and pattern switch 21+

sealed interface Shape permits Circle, Square { }
record Circle(double r) implements Shape { }
record Square(double s) implements Shape { }

double area = switch (shape) {
    case Circle c -> Math.PI * c.r() * c.r();
    case Square q -> q.s() * q.s();
};                                  // no default needed

Generics

class Box<T> {                        // type parameter
    private T value;
    T get() { return value; }
    void set(T v) { value = v; }
}
Box<String> b = new Box<>();         // <> infers the type

static <T> T first(List<T> xs) {      // generic method
    return xs.get(0);
}
static <T extends Comparable<T>> T max(T a, T b) {   // bounded
    return a.compareTo(b) >= 0 ? a : b;
}

List<? extends Number> reader;        // read items as Number
List<? super Integer> writer;         // add Integers

Type arguments must be reference types: List<Integer>, not List<int>. Generic types are erased at runtime.

Exceptions

try {
    int n = Integer.parseInt(s);
} catch (NumberFormatException | NullPointerException e) {
    System.err.println(e.getMessage());
} finally {
    cleanup();                          // always runs
}

try (var in = new Scanner(System.in)) { // closes automatically
    String line = in.nextLine();
}

throw new IllegalStateException("bad state");
void read() throws IOException { }      // declare checked exceptions

class AppException extends Exception {  // custom checked exception
    AppException(String m) { super(m); }
}
  • Checked (Exception but not RuntimeException) must be caught or declared with throws.
  • Unchecked (RuntimeException, Error) need neither.
  • Catch the most specific type first.

Common gotchas

  • == on objects compares references. Use equals.
  • int overflow wraps silently: Integer.MAX_VALUE + 1 is negative.
  • Integer division truncates: 1 / 2 is 0.
  • 0.1 + 0.2 != 0.3. Use BigDecimal for money.
  • 'a' + 1 is the int 98. Write (char) ('a' + 1) for 'b'.
  • Removing from a list inside a for-each throws ConcurrentModificationException. Use removeIf.
  • Calling a method on null throws NullPointerException.
  • Wrapper values outside -128 to 127 are separate objects, so == fails on them.
